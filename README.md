# StreamVerse - OTT Streaming Website

StreamVerse is a modern OTT streaming platform built using **HTML, CSS, and JavaScript** as part of a Web Technology CIA project.

---

## Project Overview

This project simulates a real-world OTT platform where users can:
- Browse movies and web series
- View trending content
- Manage watchlist
- View notifications
- Explore genres and series
- Access profile and downloads

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- VS Code
- Git & GitHub
