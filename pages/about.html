About StreamVerse

StreamVerse is a modern OTT streaming platform designed for movie lovers. Users can stream movies, web series, thrillers and exclusive entertainment content anytime and anywhere.


This project was developed using HTML, CSS and JavaScript as part of Web Technology CIA. The website focuses on responsive design, reusable UI components and modern OTT platform experience.


Features include:

  • Movie Streaming
  • Watchlist
  • User Profiles
  • Admin Dashboard
  • Subscription Plans
  • Downloads & Reviews
